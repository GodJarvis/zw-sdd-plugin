# 跨宿主动作契约

## 询问与选择

需要用户输入时，优先使用当前宿主可用的结构化交互能力；不可用时直接在对话中一次提出一个简短问题并等待明确回答。单选、多选、自定义输入和危险操作确认的语义必须保留。

## 进度跟踪

需要维护阶段、模块或检查项状态时，优先使用宿主原生计划或任务能力；不可用时在回复或工作流产物中维护同等状态清单。

## 独立执行单元

需要并行、隔离实现或独立审查时，优先使用宿主原生子智能体。缺少该能力时，非隔离步骤可按相同边界串行执行；强制独立审查或隔离的步骤必须停止并说明缺失能力。

## Skill 调用

统一使用逻辑 Skill ID。由宿主按原生发现和调用方式加载完整 Skill；命令、菜单或聊天入口只负责转发，不复制流程正文。

## 文件与命令

读取、创建、编辑、搜索文件及执行命令时使用宿主提供的等价能力。动作名称不是字面工具名，单次写入成功也不等于语义验证通过。
